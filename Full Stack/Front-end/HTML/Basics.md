# نوت: المرحلة 1 – أساسيات HTML

## الهيكل الأساسي للصفحة

- `<!DOCTYPE html>`: تعريف نوع المستند (HTML5).
    
- وسم `<html lang="en">` يحتوي الصفحة ويحدد اللغة.
    
- `<head>` يحتوي على بيانات الصفحة مثل الترميز (`charset`)، العنوان (`<title>`)، وإعدادات العرض (`viewport`).
    
- `<body>` يحتوي المحتوى الظاهر للمستخدم.
    

## الوسوم الأساسية للنصوص

- العناوين: `<h1>` إلى `<h6>` (حيث `<h1>` هو الأهم).
    
- الفقرات: `<p>`.
    
- كسر السطر: `<br>`.
    
- خط أفقي: `<hr>`.
    
- تنسيقات النص:
    
    - عريض: `<b>` أو `<strong>`.
        
    - مائل: `<i>` أو `<em>`.
        
    - تحته خط: `<u>`.
        

## الروابط `<a>`

- السمة الأساسية: `href` لتحديد وجهة الرابط.
    
- فتح الرابط في نفس التبويب (افتراضي).
    
- فتح الرابط في تبويب جديد باستخدام `target="_blank"`.
    
- حماية من ثغرة Tabnabbing بإضافة `rel="noopener noreferrer"`.
    
- مثال آمن:
    
    ```html
    <a href="https://example.com" target="_blank" rel="noopener noreferrer">رابط آمن</a>
    ```
    
- روابط البريد الإلكتروني باستخدام `mailto:`.
    

## الصور `<img>`

- السمات المهمة:
    
    - `src`: مسار الصورة.
        
    - `alt`: نص بديل إذا لم تظهر الصورة.
        
    - `width` و `height`: أبعاد الصورة (بالبكسل).
        
    - `loading="lazy"` لتحميل الصورة عند الحاجة.
        
- مثال:
    
    ```html
    <img src="photo.jpg" alt="My photo" width="300" loading="lazy">
    ```
    

## مفاهيم أمان مهمة

- **ثغرة Tabnabbing:** تحدث عند فتح رابط في تبويب جديد بدون حماية، مما يسمح للصفحة الجديدة بالتحكم في الصفحة الأصلية عبر `window.opener`.
    
- **الحماية:** إضافة `rel="noopener noreferrer"` مع `target="_blank"` تمنع هذه الثغرة.
