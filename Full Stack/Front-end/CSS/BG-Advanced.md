

# 🎬 الفصل: "معركة الخلفيات"  
(أو: كيف تتحكم في كل صورة بخلفية واحدة)

تخيل إنك مدير تصميم في موقع كبير.  
عندك **عنصر واحد** (مثلاً: `<div>`)، وعايز تضع **3 صور خلفه**، كل واحدة لها دور:

1. ورقة قديمة (خلفية)
2. زهرة (في الزاوية)
3. شعار (في المنتصف)

وكل واحدة لازم:
- تُضبط حجمها
- تُحدد منين تبدأ
- تُحدد هل تُقَص ولا لا

---

## 🔁 أولًا: كيف تضيف أكثر من خلفية؟

### ✅ الطريقة: فصل الصور بـ **فاصلة**

```css
.element {
  background-image: url(flower.png), url(paper.jpg), url(logo.svg);
}
```

> ✅ **الصورة الأولى هي الأقرب لك** (تظهر فوق كل الحاجات)  
> ✅ الصورة الأخيرة هي في **الخلف تمامًا**

### 💡 مثل: طبقات في برنامج تصميم (Photoshop)

```
[ الزهرة ]   ← الأعلى (أقرب للعين)
[ الورقة ]   ← الوسط
[ الشعار ]   ← الأسفل (خلف كل حاجة)
```

---

### ✅ مثال عملي (باستخدام shorthand)

```css
.hero {
  background: 
    url(flower.png) right bottom no-repeat,
    url(paper.jpg) left top repeat,
    url(logo.svg) center no-repeat;
}
```

> ✅ نفس الفكرة: كل خلفية = `url + position + repeat`  
> وكل واحدة تُفصل بفاصلة

---

## 🖼️ 1. `background-size`: "أنا بتحكم في حجم كل صورة"

> "أنا مش عايز الصورة تظهر بحجمها الطبيعي، عايز أصغرها أو أكبّرها"

### القيم:
- `100px 80px` → حجم محدد
- `contain` → أظهرها كلها (حتى لو في فراغ)
- `cover` → املأ المكان (حتى لو قصصت من الجوانب)

### ✅ مع أكثر من خلفية:

```css
background-size: 130px, 50px, cover;
```

> - أول رقم ← أول صورة (الزهرة)
> - ثاني رقم ← ثاني صورة (الورقة)
> - ثالث رقم ← ثالث صورة (الشعار)

---

## 🧭 2. `background-position`: "منين تبدأ كل صورة؟"

مثل:  
- الزهرة → `right bottom` (الزاوية السفلى اليمنى)
- الورقة → `left top` (الزاوية العليا اليسرى)
- الشعار → `center` (في المنتصف)

### ✅ مثال:
```css
background-position: right bottom, left top, center;
```

> الترتيب مهم: الأول للصورة الأولى، والثاني للثانية، وهكذا

---

## 🔁 3. `background-repeat`: "هل تكرر الصورة ولا مرة واحدة؟"

- `repeat` → تكرر في كل الاتجاهات
- `no-repeat` → مرة واحدة
- `repeat-x` → تكرار أفقي
- `repeat-y` → تكرار رأسي

```css
background-repeat: no-repeat, repeat, no-repeat;
```

> الورقة تكرر، والزهرة والشعار مرة واحدة

---

## 🏗️ 4. `background-origin`: "منين تبدأ الخلفية؟"

> "أنا عايز الصورة تبدأ منين؟ من الحد؟ من البادنج؟ من المحتوى؟"

### 3 خيارات:

| القيمة | المعنى |
|-------|--------|
| `border-box` | تبدأ من **زاوية الحد** (حتى لو الحد سُمك) |
| `padding-box` | (الافتراضي) تبدأ من **زاوية البادنج** |
| `content-box` | تبدأ من **زاوية المحتوى** (بعد البادنج)

### 💡 مثل: وضع ملصق على صندوق

- `border-box` → الملصق على الحافة الخارجية
- `padding-box` → داخل الصندوق، بعد الحافة
- `content-box` → على الورق اللي جوا، بعد البادنج

```css
background-origin: content-box;
```

---

## 🎨 5. `background-clip`: "إلى فين تظهر الخلفية؟"

> "الخلفية تظهر ورا الحد؟ ولا بس لحد البادنج؟"

### 3 خيارات:

| القيمة | المعنى |
|-------|--------|
| `border-box` | (الافتراضي) تظهر ورا **الحد** كله |
| `padding-box` | تظهر بس لحد **البادنج** — الحد يكون شفاف |
| `content-box` | تظهر بس ورا **المحتوى** — البادنج والحد شفافين

### 💡 مثل: طلاء ورنيش على خشبة

- `border-box` → الطلاء يغطي كل الحاجات
- `padding-box` → يغطي البادنج بس، الحد يفضل طبيعي
- `content-box` → يغطي بس المحتوى، الباقية شفاف

```css
background-clip: content-box;
```

---

## 🧠 خلاصة: الفرق بين `origin` و `clip`

| السؤال | `background-origin` | `background-clip` |
|-------|----------------------|-------------------|
| منين **تبدأ** الخلفية؟ | ✅ | ❌ |
| إلى فين **تظهر** الخلفية؟ | ❌ | ✅ |

> مثل:  
> - **أصل النهر** = منين يبدأ (origin)  
> - **مجرى النهر** = إلى فين يمشي (clip)

---

## 🌍 مثال واقعي: خلفية كاملة للصفحة

عايز الصورة تغطي **الشاشة كلها**، ما تسببش سكرول، وتكون مركزية.

```css
html {
  background: url(bg.jpg) no-repeat center fixed;
  background-size: cover;
}
```

- `html` → لأنه دائمًا بيمتد على الشاشة
- `center` → تمركز
- `fixed` → ما تتحركش عند السكرول
- `cover` → تغطي كل حاجة

---

## 🦸 مثال: Hero Image (صورة بارزة مع نص)

```css
.hero {
  background: url(hero.jpg) center/cover no-repeat;
  height: 600px;
  display: flex;
  align-items: center;
  justify-content: center;
  color: white;
  text-align: center;
}
```

> صورة ضخمة، نص في المنتصف، شكل احترافي

---

## ✅ خلاصة سريعة

| الخاصية               | وظيفتها                                       |
| --------------------- | --------------------------------------------- |
| `background-image`    | أضف أكثر من صورة بفاصلة                       |
| `background-size`     | حجم كل صورة (مثلاً: `cover`, `100px`)         |
| `background-position` | منين تبدأ كل صورة                             |
| `background-repeat`   | هل تكرر ولا لا؟                               |
| `background-origin`   | منين تبدأ الخلفية (من الحد، البادنج، المحتوى) |
| `background-clip`     | إلى فين تظهر الخلفية                          |
| `shorthand`           | اجمع كل الحاجات في سطر واحد                   |
