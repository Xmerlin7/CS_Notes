
# 📝 **CSS Text Effects** 
## (التحكم في النص: القص، التفاف، الكسر، والاتجاه)

> 💡 كل خاصية هنا بتحل مشكلة حقيقية:
> - النص الطويل يطلع بره
> - الكلمة الطويلة ما تنكسرش
> - النص ما يظهرش بشكل لائق
> - أو عايز تكتب من فوق لتحت (مثل الياباني)

---

## 1. `text-overflow` → "النص طال وطلع بره، إزاي أخليه يظهر؟"

### ✅ الغرض:
تحدد **إيه اللي يظهر لما النص يزيد عن الحد**.

### ✅ الشروط علشان يشتغل:
لازم يكون عندك:
```css
white-space: nowrap;  /* النص في سطر واحد */
width: محدد;           /* علشان يوصل للنهاية */
overflow: hidden;     /* ما يظهرش الزايد */
```

### 📌 القيم:

| القيمة | المعنى | مثال |
|--------|--------|------|
| `clip` | يقطع النص من غير ما يظهر حاجة | `This is very lo...` (مفيش نقاط) |
| `ellipsis` | يخفي الزايد ويضيف `...` | `This is very long...` |

### 💡 مثال:
```css
.title {
  white-space: nowrap;
  width: 200px;
  border: 1px solid #000;
  overflow: hidden;
  text-overflow: ellipsis;
}
```

> النتيجة:  
> `عنوان طويل جدًا لا ين...`

---

### ✅ تلميح ذكي:
عايز تظهر المحتوى لما يمر الماوس؟
```css
.title:hover {
  overflow: visible;
  white-space: normal;
}
```

✅ النتيجة: لما تحوم، يظهر النص كله

---

## 2. `word-wrap` (أو `overflow-wrap`) → "الكلمة الطويلة مش بتنكسر، خليها تنكسر!"

### ✅ الغرض:
تسيب **الكلمة الطويلة تنكسر وتنزل سطر جديد** — حتى لو في منتصف الكلمة.

### 💡 مثال:
> `thisisaveryverylongwordindeed`  
> بدون `word-wrap`: تطلع بره  
> مع `word-wrap: break-word`: تنكسر وتظهر

### ✅ القيم:

| القيمة | المعنى |
|--------|--------|
| `normal` | ما يكسرش الكلمة (تطلع بره) |
| `break-word` | اكسر الكلمة لو لازم |

```css
p {
  word-wrap: break-word;
  /* أو */
  overflow-wrap: break-word; /* الاسم الحديث */
}
```

> ✅ استخدم `overflow-wrap` لو بتحب التحديثات

---

## 3. `word-break` → "منين أكسر الكلمة؟"

### ✅ الفرق بينه وبين `word-wrap`:
- `word-wrap`: يكسر **باستثناء** الكلمات العادية
- `word-break`: يتحكم في **قواعد الكسر من الأساس**

### ✅ القيم:

| القيمة | المعنى |
|--------|--------|
| `keep-all` | ما تكسرش الكلمة (مثالي للغات مثل الصينية) |
| `break-all` | اكسر في أي مكان، حتى لو في منتصف كلمة إنجليزية |
| `normal` | السلوك العادي (كسر عند المسافات) |

### 💡 متى تستخدم إيه؟

| الحالة | استخدم |
|-------|--------|
| نص عربي/إنجليزي عادي | `word-wrap: break-word` |
| نص صيني/ياباني | `word-break: keep-all` |
| جدول ضيق، وعايز كل حاجة تنكسر | `word-break: break-all` |

### مثال:
```css
.table-cell {
  width: 100px;
  word-break: break-all;
}
```

---

## 4. `writing-mode` → "عايز أكتب من فوق لتحت!"

### ✅ الغرض:
تحدد **اتجاه النص**: أفقي ولا رأسي؟ من اليمين لليسار ولا العكس؟

### ✅ القيم الشائعة:

| القيمة | المعنى |
|--------|--------|
| `horizontal-tb` | أفقي، من أعلى لأسفل (الافتراضي) |
| `vertical-rl` | رأسي، من اليمين لليسار (مثل الياباني) |
| `vertical-lr` | رأسي، من اليسار لليمين |

### 💡 مثال:
```css
.vertical-text {
  writing-mode: vertical-rl;
  text-orientation: upright; /* يبقي الحروف منتصبة */
}
```

> النتيجة: نص يقرأ من **يمين الشاشة، من فوق لتحت**

## ✅ جدول مقارنة سريع

| الخاصية | الغرض | متى تستخدمها؟ |
|--------|------|----------------|
| `text-overflow: ellipsis` | نص طويل → يظهر `...` | عناوين، أسماء ملفات |
| `word-wrap: break-word` | كلمة طويلة تنكسر | محتوى ديناميكي، تعليقات |
| `word-break: break-all` | اكسر في أي مكان | جداول ضيقة |
| `writing-mode: vertical-rl` | نص رأسي | تصميمات فنية، لغات شرق آسيوية |

> - `word-break` → "منين أكسر الكلمة؟"  
> - `writing-mode` → "عايز أكتب من فوق لتحت!"
