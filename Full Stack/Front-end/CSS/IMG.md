# 🎯 **ملخص شامل: كل ما يخص الصور في CSS**

---

## 1. أنواع الصور في الويب

| النوع | الاستخدام | المميزات |
|------|----------|---------|
| `.jpg` | صور واقعية، مناظر | ضغط جيد، بس مش شفاف |
| `.png` | شعارات، أيقونات | يدعم الشفافية (Alpha) |
| `.gif` | صور متحركة | بسيطة، بس جودة منخفضة |
| `.webp` | حديث، أداء عالي | جودة عالية، حجم صغير، يدعم الشفافية والحركة |
| `.svg` | أيقونات، رسومات | متجهية (ما تتأثرش بالتكبير)، حجم صغير |

> ✅ نصيحة: استخدم `.webp` أو `.svg` كل ما تقدر

---

## 2. `object-fit` → "كيف تظهر الصورة داخل العنصر؟"

مثل: صورة كبيرة في كارت صغير

### ✅ القيم:

| القيمة | المعنى | مثل |
|--------|--------|------|
| `fill` | تمدد الصورة لتملأ المكان (حتى لو تشوهت) | ❌ مش محبوب |
| `cover` | تغطي الصورة المكان كله، ولو قُطعت من الجوانب | ✅ مثالي للخلفيات |
| `contain` | تظهر الصورة كلها، ولو كان في فراغ | ✅ مثالي للشعارات |
| `scale-down` | مثل `contain`، بس لو الصورة أصغر، ما تكبّرهاش | |
| `none` | ما تغيّرش الحجم | |

### 💡 مثال:
```css
.card img {
  width: 300px;
  height: 200px;
  object-fit: cover;
  border-radius: 12px;
}
```

> صورة تغطي الكارت بدون فراغات

---

## 3. `object-position` → "أي جزء من الصورة تظهر؟"

> يُستخدم مع `object-fit: cover` أو `contain`

### 💡 مثال:
```css
img {
  object-fit: cover;
  object-position: top; /* خلي الوجه ظاهر، مش يقطع */
}
```

> مفيد في صور الأشخاص — تثبت الجزء المهم

---

## 4. `clip-path` → "قص الصورة على شكل معين"

> ✅ يسمح لك تقص الصورة على شكل دائرة، مضلع، أو مسار معقد

### ✅ أمثلة:

```css
.circle {
  clip-path: circle(50%);
}

.polygon {
  clip-path: polygon(50% 0%, 100% 50%, 50% 100%, 0% 50%);
}

.heart {
  clip-path: path('M12 21.35l-1.45-1.32C5.4 15.36 2 12.28 2 8.5 2 5.42 4.42 3 7.5 3c1.74 0 3.41.81 4.5 2.09C13.09 3.81 14.76 3 16.5 3 19.58 3 22 5.42 22 8.5c0 3.78-3.4 6.86-8.55 11.54L12 21.35z');
}
```

> ✅ النتيجة: صورة على شكل قلب، مثلث، نجمة، إلخ

---

## 5. `mask-image` → "اخلع جزء من الصورة باستخدام صورة أخرى"

> ✅ مثل "ستنسل" — تستخدم صورة أو تدرج علشان تخفي أجزاء من الصورة

### 💡 مثال:
```css
.masked {
  mask-image: linear-gradient(to bottom, black 50%, transparent 100%);
  /* أو */
  mask-image: url(mask-pattern.png);
  mask-size: cover;
  mask-repeat: no-repeat;
}
```

> النتيجة: الصورة تختفي تدريجيًا من الأعلى للأسفل

---

### ✅ الفرق بين `clip-path` و `mask`:

| `clip-path` | `mask-image` |
|------------|--------------|
| يقص على شكل حاد | يمكن يكون تدريجي (تدرج) |
| بس أشكال هندسية | يمكن يكون أي صورة أو تدرج |
| لا يدعم التدرج | يدعم التدرج والصور |
| أداء أفضل | أداء أقل قليلًا |

---

## 6. `filter` → "تأثيرات على الصورة (مثل الفوتوشوب)"

| الدالة | المثال |
|-------|--------|
| `blur(3px)` | موّه الصورة |
| `brightness(150%)` | أضيء الصورة |
| `contrast(120%)` | زود التباين |
| `grayscale(100%)` | حول للأسود والأبيض |
| `sepia(80%)` | تأثير صورة قديمة |
| `hue-rotate(90deg)` | غير الألوان |
| `drop-shadow(4px 4px 6px black)` | ظل يتبع الشكل |

### 💡 مثال:
```css
.img-hover {
  filter: grayscale(100%) contrast(120%);
  transition: filter 0.3s ease;
}

.img-hover:hover {
  filter: none;
}
```

> صورة تتحول من أسود وأبيض إلى ملونة عند الهوفر

---

## 7. `background-image` vs `<img>`

| `<img>` | `background-image` |
|--------|---------------------|
| للـ **محتوى** (جزء من القصة) | للـ **التصميم** (ديكور) |
| يُقرأ من قبل قارئ الشاشة (مع `alt`) | مش بيُقرأ |
| يمكن حفظه | لا يمكن حفظه بسهولة |
| يُستخدم في المحتوى (مقالات، منتجات) | يُستخدم في الخلفيات، التأثيرات |

> ✅ استخدم `<img>` مع `alt` للمحتوى  
> ✅ استخدم `background-image` للخلفيات

---

## 8. `image-set()` → "اختر الصورة حسب دقة الشاشة"

```css
.hero {
  background-image: image-set(
    url(img-low.jpg) 1x,
    url(img-high.jpg) 2x
  );
}
```

> ✅ يعطي صورة عالية الجودة للـ Retina، وصورة صغيرة للهواتف

---

## 9. `aspect-ratio` → "احفظ نسبة العرض إلى الارتفاع"

```css
.card img {
  width: 100%;
  aspect-ratio: 16 / 9; /* فيديو */
  /* أو */
  aspect-ratio: 1 / 1; /* صورة مربعة */
}
```

> ✅ يمنع "التشويه" ويحافظ على الشكل

---

## ✅ خلاصة واحدة تُخزن في دماغك

> - `object-fit: cover` → صورة تملأ المكان  
> - `object-position: top` → خلي الوجه ظاهر  
> - `clip-path` → قص على شكل دائرة أو قلب  
> - `mask-image` → اختفاء تدريجي (مثل التلاشي)  
> - `filter` → تأثيرات فوتوشوب (blur, grayscale, drop-shadow)  
> - `<img>` → للمحتوى | `background-image` → للتصميم  
> - `aspect-ratio` → حافظ على الشكل  
> - `image-set()` → صورة مناسبة لكل شاشة
