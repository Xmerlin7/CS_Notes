

## ✅ مثال بسيط: مثلث لأعلى

```css
.arrow-up {
  width: 0;
  height: 0;
  border: 10px solid transparent;
  border-bottom-color: black;
}
```

> مثلث أسود يشيل لأعلى

لأن:
- الحد السفلي = أسود
- الباقي = شفاف
- والشكل الهندسي يجبره يظهر كمثلث

---

## 💡 كيف تتخيلها في دماغك؟

| الشكل | المعنى |
|------|--------|
| `border: 5px solid red` | "الكل لونه أحمر" |
| `border: 5px solid transparent` | "الكل شفاف" |
| `border-bottom-color: black` | "بس الحد السفلي يبقى أسود" |
| النتيجة | مثلث أسود في الأسفل |

> ✅ المثلث مش "سحر" — هو نتيجة **الشكل الهندسي للـ border**

---

## ✅ خلاصة واحدة تُخزن في دماغك

> 🔺 **الـ border مش خط — هو 4 مثلثات حول عنصر**  
> - لما تكتب `border: 5px solid red` → تلون كل المثلثات
> - لما تكتب `border: 5px solid transparent` ثم تلون واحد بس → تلاقي مثلث واحد
> - `::after` مع `width: 0` و `height: 0` = ورشة صغيرة نرسم فيها المثلث
