

```css
border-image: url(border.png) 30 stretch;
```

ده بيستخدم صورة كـ **حد فعلي (border)**، ورقم `30` هو **أهم جزء تقريبًا** في الأمر.

---

## 🎯 ماذا يفعل الرقم `30`؟

الرقم `30` هو **`border-image-slice`** — وهو **بيقسم الصورة إلى 9 أجزاء**، وبيحدد:

> ✅ أي جزء من الصورة يُستخدم في **الزوايا**  
> ✅ وأي جزء يُستخدم في **الجوانب (الأطراف)**  
> ✅ وأي جزء يُهمل (المنتصف)

---

## 🧩 تخيل الصورة: مقسمة كـ "لعبة 9 مربعات"

```
+--------+--------+--------+
|        |        |        |
|   1    |   2    |   3    |
|        |        |        |
+--------+--------+--------+
|        |        |        |
|   4    |   5    |   6    |
|        |        |        |
+--------+--------+--------+
|        |        |        |
|   7    |   8    |   9    |
|        |        |        |
+--------+--------+--------+
```

- الزوايا (1, 3, 7, 9) → تُستخدم كما هي (مافتّش ولا ممدد)
- الجوانب (2, 4, 6, 8) → تُمدد أو تُكرر حسب `stretch`, `repeat`, `round`
- المنتصف (5) → يُهمل (إلا إذا استخدمت `fill`)

---

## 🔢 ما معنى `30`؟

الرقم `30` يعني:

> "اقطع 30 بكسل من كل حافة للصورة، من الداخل"

يعني:
- من الأعلى: 30px
- من اليمين: 30px
- من الأسفل: 30px
- من اليسار: 30px

وده بيحدد **الحدود بين الزوايا والجوانب**.

---

## 🖼️ مثال عملي

لو عندك صورة `border.png` بحجم `100x100px`:

```css
border-image: url(border.png) 30 stretch;
```

النتيجة:
- الزوايا: مربعات `30x30px` من كل ركن
- الجوانب: شرائط `30px` عرض من الأعلى/الجانبين/الأسفل
- المنتصف: يُهمل

---

## 🛠️ شرح كل جزء في السطر

```css
border-image: url(border.png) 30 stretch;
```

| الجزء | المعنى |
|------|--------|
| `url(border.png)` | الصورة اللي تستخدمها كحد |
| `30` | `border-image-slice` — يقطع 30px من كل حافة |
| `stretch` | كيف يُعرض الجزء الأوسط من الحافة (يتمدد) |

---

## 🔁 خيارات بدل `stretch`

| القيمة | التأثير |
|-------|--------|
| `stretch` | يمدد الصورة (مثل "بلاستيك") |
| `repeat` | يكرر الصورة (مثل خلفية) |
| `round` | يكرر الصورة، لكن يُعدّل الحجم علشان ما يقطعش |
| `space` | يكرر الصورة مع فراغات بينها |

مثال:
```css
border-image: url(border.png) 30 round;
```

---

## ✅ نصائح مهمة

1. ✅ استخدم `border-image-slice: 30;` بس إذا كنت عارف إن الصورة فيها حد واضح في أول 30px
2. ✅ لو الصورة 2D (مثل خط متعرج)، `30` رقم مناسب
3. ❌ لا تستخدم رقم أكبر من نصف حجم الصورة (مثلاً: صورة 50px، لا تستخدم `30` — هتقطع كل حاجة!)
4. ✅ جرب `border: 20px solid transparent;` أولًا — علشان تحدد حجم الحد

---

## 💡 مثال كامل

```css
.fancy-box {
  width: 300px;
  height: 200px;
  border: 30px solid transparent;
  border-image: url(border.png) 30 round;
}
```

> ✅ يعطيك حدود من الصورة، مكررة بشكل نظيف
